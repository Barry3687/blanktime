# 留白日程 · Blanktime

網站：https://barry3687.github.io/blanktime/

把課表、重要行事曆、讀書計畫、逐觀念教材和原版番茄鐘放在同一個滿版「暮光紫藤」工作空間（低飽和深紫灰＋柔薰衣草紫）。僅使用免費功能，不綁付款方式、不啟用付費模型 API。

## 目前功能

- Google 登入；Supabase 依帳號保存整理後的課程、理解進度、A/B/C/F 熟悉度、行程及同一份番茄鐘狀態與紀錄。原始 PDF、Word、PPT、圖片不會上傳。
- 訪客模式只存在目前瀏覽器，與登入帳號快取分開；訪客資料需預覽確認才合併。
- 今天顯示完整課表、讀書、休息與彈性時間。手動時間可精確到 5 分鐘，三小時固定課程按一小時分段顯示，支援重複課表與停課日期。
- 月曆、週檢視與日期詳情只列重要事項，包含作業、報告、考試及手動指定事項；截止日與安排日不同時，另在截止日標示。休息與彈性不塞入行事曆。
- 已過但未完成的事項保留原日期、時段並標示「未完成」，不自動搬動。四象限只列使用者核對加入的事項，重要程度可調整。
- 一週規則排程先預覽、確認後加入每日安排；避開固定課表，使用 30／60 分鐘讀書單位，每次休息與每日獨立彈性時間至少 30 分鐘，排不下的任務明列待安排。這不是網站即時呼叫模型。
- ChatGPT／Gemini 教材包匯入：驗證、預覽、確認，支援多門課與版本檢查；重新匯入保留理解進度。教材與學習進度可備份與合併還原。
- 教學依序為白話理解、公式與符號、驗證題；長推導可展開。提交選擇題後，答對或答錯都立即顯示正確答案及各選項解析，作答前隱藏。理解完成須自己確認，不因單題答對就升為 A。
- 原版番茄鐘背景、城市、日夜、天氣、聲音、設定及次數統計保留，頂列與原頁共用一份倒數。跨頁／重整持續，登入後透過伺服器時間與版本檢查同步。

## 暮光紫藤版本（2026-11-26）

- 滿版深紫灰與薰衣草紫、語意左色條、現在時間線、等寬數字、四象限淡底標與避讓膠囊標籤。頂列順序維持原樣，番茄鐘左側同步狀態，右側設定齒輪；原版番茄鐘檔案未修改。
- 每日安排可切任意日期，月曆已選日期可切「重要事項／完整時間表」。固定課表有獨立調課入口，停課例外與補課一次建立；移除操作均確認。
- 各門教材獨立 Deadline，同步於 schedule，首頁按到期時間列出。重排扣除已完成時段工時，讀書卡片可直達對應觀念。
- 自託管 MathJax 3.2.2 單檔 SVG，包含字型資料與 Apache 2.0 授權，不從外部 CDN 載入公式資源。題幹、選項與即時解析均支援 LaTeX。已載入頁面或本機部署可離線排版；本版未提供整站首次離線下載。
- 解題批改改為預設收合的一鍵複製，附題目、選項、答案、草稿、公式與來源頁碼，交由自己的 ChatGPT／Gemini 對話處理。沒有 /api/status 或 /api/review 呼叫。
- 匯入／原始預覽側欄可收合並記憶，正文舒適行寬；成功匯入清空 JSON。說明區依登入／訪客切換。
- 課程刪除移至 30 天跨裝置垃圾桶，保留理解進度與熟悉度；可還原、確認永久清除，到期在啟動／同步時清除。生命週期採 kind=course 的 blanktime.course-state/v1 包裝與永久清除標記，舊裸教材相容，不需改 SQL CHECK。標記阻止離線舊裝置與舊備份復活。
- 設定包含完整備份、垃圾桶、作息與閱讀偏好、同步／快取資訊。blanktime.backup/v2 匯出教材、進度、熟悉度、垃圾桶、課表與行程、各科期限、番茄鐘紀錄與偏好；合併還原相容 v1／v2，保留目前倒數。原始教材不含在備份或同步。

永久清除會清除當前課程內容、理解進度、熟悉度與本機接續位置，保留無教材的防復活標記。既有 blanktime_operations 重送去重稽核歷史沿用原資料庫規則，沒有變更或刪除 SQL 稽核表。

## 驗證與限制

2026-11-26 已完成真實 Google 登入及 Supabase 讀寫驗收。兩個獨立資料快取的頁面，實際驗證行程新增／完成／移除、整理後教材、理解進度、熟悉度及番茄鐘開始／暫停／重設的雙向同步。第二頁用 sessionStorage 保存獨立資料快取，沒有依賴第一頁的 localStorage 廣播；身份驗證仍使用正常 Google 登入。

這是同一台電腦上的兩個獨立客戶端。使用者已回報手機查看正常；另一帳號的正式端到端測試與本輪新增功能的完整雙實機驗收尚未進行。390px 響應式檢查已通過，題目前後的解析顯示已從正常入口驗證。真實專注完成次數的長時間雙裝置結算仍待後續實機驗收；去重、衝突與 SQL 隔離有自動測試。

國定假日自動資料、系統通知與即時 AI 解題批改尚未提供。假日可人工新增或核對後匯入；網頁關閉後不保證播音或提醒。未登入時，清除瀏覽器資料會清除訪客內容。原始教材預覽只保存在頁面記憶體。

本輪正常入口已實測教材匯入、答對／答錯即時公式解析、草稿複製、側欄收合、完整備份匯出／合併還原、垃圾桶移入／還原、各科期限、一週預覽、調課及時段直達教材。Chrome 桌面與 390px 的今天、行事曆、教材、讀書計畫、番茄鐘及設定視窗無橫向溢出，Console 無 404 或未捕獲錯誤；番茄鐘跨頁倒數沿用同一狀態。10 組 Node 檢查及瀏覽器公式自動測試通過。雙客戶端新增同步測試採獨立本機快取與模擬 RPC，未把模擬測試當作新增功能的雙實機驗收。

## 開發檢查

一般本機預覽：`python -m http.server 8765`。啟動後開啟 `/scripts/math-render.test.html` 執行瀏覽器 SVG 自動測試；須顯示 PASS，涵蓋公式、題幹、選項與動態解析，並檢查零外部資源與額外字型。

真實登入驗收：`python scripts/preview-auth.py`。需先取得使用者確認，暫時允許 `http://127.0.0.1:8765/` 作為 Supabase 回傳網址，驗收後移除。`?isolatedQa=1` 的第二頁只在這個本機伺服器使用獨立資料快取，不改正式設定、也不讀取或複製登入憑證。HTTP 紀錄不輸出登入回傳 query。

- `node scripts/integration.test.cjs`
- `node scripts/planner.test.cjs`
- `node scripts/storage.test.cjs`
- `node scripts/dusk.test.cjs`
- `node scripts/cloud.test.cjs`

- `node scripts/cloud-sql.test.cjs`（另安裝 @electric-sql/pglite 或傳入 dist/index.cjs 路徑）

教材格式與教練：skills/blanktime-study-coach/。舊 modules/learning/backend/ 只保留原始參考，不在 GitHub Pages 執行。
