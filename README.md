# 留白日程 · Blanktime

網站：https://barry3687.github.io/blanktime/

把課表、行事曆、讀書計畫、逐觀念教材與原版番茄鐘整合在同一個滿版日常工作空間。預設採用「暮光紫藤」深色介面，並可在設定中切換 7 套非綠色深／淺佈景主題。全站僅使用免費功能，不綁定付款方式、不啟用付費模型 API。

## 目前功能

### 帳號、跨裝置同步與設定
- **Google 登入與私有同步**：透過 Supabase 依帳號隔離保存整理後的課程、理解進度、A／B／C／F 熟悉度、30 天垃圾桶狀態、課表與行程、各科期限及同一份番茄鐘狀態與紀錄；原始 PDF／Word／PPT／圖片僅在頁面記憶體預覽，絕不上傳。
- **頂列快速操作**：頂列順序為品牌 → 主要分頁 → 帳號 → 可點擊的同步狀態按鈕（點一下立即重新同步）→ 共享番茄鐘方塊 → `⚙` 設定齒輪。
- **統一介面體驗**：`⚙ 設定` 內提供 **7 套非綠色佈景主題**（深色：暮光紫藤、暮色藍窗、葡萄酒紅、深夜書房；淺色：暖紙墨韻、晴空岩灰、淺紫丁香紙），主站、所有彈窗、自訂確認視窗、課表與學習頁同步套用；全站彈窗統一右上角 `✕` 關閉並支援點擊外部遮罩關閉。
- **完整備份與還原（`blanktime.backup/v2`）**：一鍵匯出教材、進度、熟悉度、垃圾桶、固定課表、行事曆、各科期限、番茄鐘紀錄與介面偏好；合併還原向下相容 `v1`，保留目前進行中的倒數。訪客模式與登入帳號快取隔離，登入後須預覽確認才合併訪客資料。

### 每日安排、週日～週六課表與行事曆
- **每日安排與平靜未完成提醒**：呈現完整一整天（固定課表、讀書、休息、彈性時間），三小時課程按一小時分段顯示，手動時間精確至 5 分鐘。右上角提供日期選擇與並排的「前一天／後一天／回今天」。讀書時段提供明確的「完成」與「未完成」按鈕；有未完成課程時，頂列下方以低干擾平靜提示條列出尚未完成的課程（全數完成時自動隱藏不佔空間）。
- **週日～週六固定課表（08:00–22:00）與課程詳細內容**：行事曆下方呈現視覺化每週課表網格。點擊每日安排、行事曆、週檢視或課表中的任一課程名稱，即可開啟「課程詳細內容」查看日期、課名、授課教授、教室、可連結的教材與該科考試期限，並直接執行 **「調課」**（原日停課＋新增補課時段）或 **「停課（不補課）」**（僅釋出該日時段），也可撤銷既有停課／調課紀錄。支援將 ChatGPT／Gemini 整理的 `blanktime.schedule/v1` JSON 預覽匯入。
- **月曆與完整週檢視**：月曆自動標示作業、報告、考試、各科考試／複習期限、重要活動與假日，右側日期詳情可切換「只看重要事項／顯示完整時間表」。週檢視呈現本週每日完整課程與時段規劃，並支援切換上一週／回本週／下一週。
- **優先順序四象限與一週規則排程**：四象限依緊急與重要程度呈現使用者核對事項（附重要程度滑桿與防重疊避讓）。各門教材可設獨立考試／複習 Deadline；規則排程先預覽再確認加入，採 30／60 分鐘讀書單位、每段休息與每日獨立彈性時間至少 30 分鐘，重排時自動扣除已完成時段工時，排不下明列待安排。點讀書時段可直接跳轉至對應教材與觀念。

### 逐觀念教材與原版番茄鐘
- **免 API 教材包與 30 天跨裝置垃圾桶**：匯入由 ChatGPT／Gemini 依 `skills/blanktime-study-coach/` 整理的 `blanktime.study-package/v1` JSON，先驗證預覽再確認，支援多門課、版本衝突保護與重匯入保留進度。右側匯入／原始預覽側欄可收合記憶。刪除課程移入 30 天跨裝置垃圾桶（保留進度與熟悉度），可還原或經二次確認永久清除，逾期自動清除。
- **逐觀念學習與純本地 MathJax**：依序呈現白話理解、公式與適用條件、四選一驗證題（提交後不論答對錯立即顯示正解與全部選項解析；理解確認與 A／B／C／F 熟悉度獨立記錄）。自託管 MathJax 3.2.2 `tex-svg.js`（Apache 2.0 授權），零外部 CDN 依賴，離線亦可排版公式。解題批改為預設收合的一鍵複製區，複製題目、答案、草稿與來源頁碼交給 ChatGPT／Gemini 批改。
- **原版窗邊番茄鐘**：完整保留原版風景、城市、日夜、天氣、聲音、設定與統計，與頂列共用 `window-seat-pomodoro-v1` 單一倒數狀態並跨頁持續，與課表／讀書卡片維持各自獨立。

## 驗證與限制

- **雲端與跨客戶端狀態**：已完成真實 Google 登入與 Supabase 讀寫驗收，並於同電腦兩個獨立快取客戶端驗證行程、整理後教材、進度、熟悉度及番茄鐘開始／暫停／重設雙向同步；另有多組自動化測試驗證垃圾桶生命週期、衝突重試、CAS 與 PGlite SQL RLS 隔離。另一帳號正式端到端測試、本輪新增功能的雙實體裝置實測與長時間專注完成結算仍待實機補測。
- **目前限制**：國定假日自動資料、系統推播通知與網站內即時 AI 批改尚未提供（假日可手動新增或整理後匯入；關閉網頁後不保證播音或提醒）。純本地 MathJax 支援已載入頁面或本機部署離線排版，未提供整站首次離線下載。未登入訪客清除瀏覽器資料會遺失訪客內容；原始教材預覽僅存在頁面記憶體。永久清除課程會清除當前內容、進度與熟悉度並留下防復活標記，既有 `blanktime_operations` 去重稽核表則沿用原資料庫規則。

## 開發與測試檢查

一般本機預覽：`python -m http.server 8765`，再開啟 `http://127.0.0.1:8765/`（公式瀏覽器自動測試頁：`/scripts/math-render.test.html`，須確認顯示 PASS 且零外部 CDN 請求）。

真實 Google 登入本機驗收：`python scripts/preview-auth.py`（僅綁 `127.0.0.1`，須先取得使用者確認暫時允許本機回傳網址並於驗收後移除，正式 `cloud/config.json` 不改動；HTTP 紀錄不輸出 OAuth callback query）。

自動化檢查清單：
- `node scripts/check.cjs`
- `node scripts/integration.test.cjs`
- `node scripts/planner.test.cjs`
- `node scripts/storage.test.cjs`
- `node scripts/dusk.test.cjs`
- `node scripts/workspace.test.cjs`
- `node scripts/cloud.test.cjs`
- `node scripts/cloud-app.test.cjs`
- `node scripts/cloud-sql.test.cjs`（需另安裝 `@electric-sql/pglite` 或傳入 `dist/index.cjs` 路徑）
- `node modules/learning/tests/core.test.js`
- `node modules/learning/tests/figures.test.js`

由 `main` 根目錄發布 GitHub Pages。公開倉庫僅含程式碼、自託管靜態資源與自編範例；`cloud/config.json` 僅含公開 publishable key，不含 `service_role`、Google client secret 或個人教材。

## 本輪驗收補充

本輪全部 11 組 Node 檢查通過。新增測試涵蓋手動完成／未完成與提示條資料、停課不補課／調課／撤銷、月曆與完整週檢視的各科期限、七套主題及 iframe 一致性、文字對比、教材跳轉通知、原生確認與 CDN 舊碼殘留防護，以及主題備份相容性。同步協調測試另涵蓋手動未完成、撤銷調課與停課的獨立客戶端同步；模擬 RPC 不等同於雙實機驗收。

正常入口已實測課表匯入、課程詳情、教授與教室、停課與撤銷、五分鐘調課、綁定教材、期限連動、完整週切換、完成狀態與提示條、自訂確認框及遮罩關閉。桌面與 390px 深／淺主題各頁無整頁橫向溢出，課表保留區內橫向捲動，Console 無 404 或未捕獲錯誤。正式網站已確認登入後的同步按鈕會由同步中回到已同步。

更嚴格的離線資源驗收：執行 `python scripts/preview-offline.py`，開啟 `http://127.0.0.1:8766/`。測試伺服器用 CSP 封鎖外部腳本、連線與字型，從正常入口匯入自編教材後，公式、題幹、選項與即時解析仍產生本機 SVG，沒有外部資源阻擋錯誤。這不變更正式網站設定，也不宣稱提供整站首次離線下載。

所有月曆、完整週檢視與每週固定課表均以星期日為一週第一天，依「日、一、二、三、四、五、六」排列；週末底色仍標示星期日與星期六，既有 weekday 0–6 資料不變。
