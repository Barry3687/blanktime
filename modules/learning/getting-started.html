用 ChatGPT／Gemini 整理教材

不需要模型 API 金鑰。網站讀取整理好的教材包，教學與題目可直接在網站上使用。

  1. 在主網站教材匯入區複製整理指令，附上你的 PDF、Word、投影片或圖片。
  2. 提供課程名稱、章節範圍與教材頁碼；看不清楚的內容先確認，避免猜測。
  3. 請輸出 blanktime.study-package/v1 JSON。每個觀念包含白話解釋、公式與符號、來源頁碼、四選一題與每個選項的解析。
  4. 回到主網站選擇教材包或貼上 JSON，按預覽，核對章節、警告與版本後確認匯入。
  5. 已登入時，整理後教材與理解進度會同步到帳號；原始檔案不會上傳。訪客模式只保存在目前瀏覽器。

同一課程請維持 courseId，修訂教材時增加 revision；同版內容衝突或舊版本不會覆蓋既有教材。章節熟悉度 A／B／C／F 由你評估。

使用設定中的完整備份保存教材、進度、課表與紀錄。刪除課程後可在 30 天垃圾桶內還原。
